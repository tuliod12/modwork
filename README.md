# ModWork

Site institucional minimalista da ModWork.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch **main**, pasta **/(root)** e clique em **Save**.

O site é estático, sem build ou dependências. O botão do WhatsApp está configurado para `+55 34 99225-3561`.

## Arquivos

- `index.html`: conteúdo e estrutura
- `styles.css`: identidade visual responsiva
- `script.js`: menu, ano atual e links do WhatsApp
- `assets/`: logo, símbolo e favicon

## Observação

Antes da publicação comercial, revise informações legais, política de privacidade e condições do curso.
